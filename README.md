# 🍃 LAST LEAF — A Journey of Resilience

> **Every ending is a chance to bounce back.**

**Last Leaf** is a small 2D game developed using the Godot Engine for the **Bounce Back Game Jam**. Built around the theme of resilience, the game explores the idea of continuing forward even when things get difficult.

The project focuses on simple gameplay, engaging visuals, and a meaningful concept — proving that even the smallest leaf can find the strength to keep going.

---

## 🎮 About the Game

Last Leaf is a game-jam project inspired by the idea of perseverance and bouncing back.

Through its gameplay and visual storytelling, the project aims to create a simple yet memorable experience.

## 🚀 Getting Started

To run the project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/Debartha-Saha-coder/lilnbouncesback.git
   ```

2. Open **Godot Engine**.
3. Select **Import**.
4. Navigate to the cloned repository and locate the Godot project file (`project.godot`) inside `lilknight_bouncesback`.
5. Import and run the project.
